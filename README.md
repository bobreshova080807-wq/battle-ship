# Морской бой с минами и подводными лодками

Задача 22 на 2 аттестацию по ООП.

## Описание модели

Игра "Морской бой" с расширенной механикой: минами, подводными лодками и тральщиками.

### Основные классы (Model)

- **Player** — игрок с именем, флотом, полем и знаниями о противнике
- **Fleet** — флот игрока (корабли + мины)
- **Ship** — корабль определённого типа (катер, эсминец, крейсер, линкор, подлодка, тральщик)
- **Mine** — морская мина с радиусом взрыва
- **Board** — физическое поле 10×10 с реальным расположением кораблей и мин
- **Knowledge** — знания игрока о поле противника (инкапсуляция информации)
- **Coordinate** — координаты клетки на поле (row, col)

### Типы кораблей (ShipType)

| Тип | Размер | Количество | Особенность |
|-----|--------|------------|-------------|
| Катер (BOAT) | 1 | 4 | Обычный корабль |
| Эсминец (DESTROYER) | 2 | 3 | Обычный корабль |
| Крейсер (CRUISER) | 3 | 2 | Обычный корабль |
| Линкор (BATTLESHIP) | 4 | 1 | Обычный корабль |
| Подводная лодка (SUBMARINE) | 1 | 2 | Скрыта от обычных выстрелов |
| Тральщик (MINESWEEPER) | 2 | 1 | Обезвреживает мины в радиусе 1 |

### Состояния клетки (CellState)

- `WATER` — вода (не обстреляна)
- `SHIP` — корабль (не обстрелян)
- `SUBMARINE` — подводная лодка (скрыта)
- `MINE` — мина (скрыта)
- `MINESWEEPER` — тральщик
- `MISS` — промах
- `HIT` — попадание
- `SUNK` — потоплен
- `MINE_EXPLODED` — мина взорвалась
- `CLEARED` — обезврежена тральщиком

### Результат выстрела (ShotResult)

- `MISS` — промах
- `HIT` — попадание в корабль
- `SUNK` — корабль потоплен
- `MINE_HIT` — попал в мину
- `SUBMARINE_MISSED` — выстрел в подлодку (не обнаружена)
- `MINE_CLEARED` — мина обезврежена тральщиком
- `ALREADY_SHOT` — клетка уже обстреляна

## Правила игры

### Расстановка флота

1. Корабли не могут выходить за пределы поля 10×10
2. Корабли не могут пересекаться
3. Корабли не могут касаться друг друга (включая диагонали)
4. Мины размещаются на пустых клетках (не на кораблях)

### Ход игры

1. Игроки по очереди стреляют по полю противника
2. При попадании в корабль — ход продолжается
3. При промахе — ход переходит к противнику
4. Подводная лодка не обнаруживается обычным выстрелом (считается промахом)
5. При попадании в мину — взрыв по площади 3×3, повреждает корабли вокруг
6. Тральщик обезвреживает мины в радиусе 1 клетки

### Условия победы

Игра заканчивается, когда все корабли одного из игроков потоплены.

## Архитектура

### Отделение механики от вывода

Механика игры (`GameService`) не печатает в консоль. Вместо этого она возвращает список событий (`GameEvent`), которые обрабатывает слой вывода (`Demo`).

### Паттерн Strategy

Стратегия стрельбы вынесена в интерфейс `ShotStrategy` с тремя реализациями:
- `RandomStrategy` — случайный выбор клетки
- `CheckerBoardStrategy` — шахматный порядок
- `SmartStrategy` — добивание раненых кораблей

### Воспроизводимость

Все случайные величины берутся из одного генератора `Random` с задаваемым зерном. Один и тот же посев даёт одну и ту же партию.
